## Sonidos sintetizados para este kit (sin muestras de terceros)

Generados con `scripts/sintetizar_sfx.py` (numpy). No vienen de ninguna grabación ajena, así que no hay licencia de terceros
que revisar. `plan.py` vuelve a generar el riser y el PUM a la medida de cada video con el mismo script.

| archivo | para qué sirve |
|---|---|
| riser-sint-3s.wav | riser ascendente de muestra (el real se hace a la duración exacta de "el canal donde oler bien") |
| pum-sint.wav | PUM grave y corto para "SIEMPRE" |
| rayo-sint.wav | chisporroteo eléctrico para la Rafaguiza |
| shimmer-sint.wav | brillo suave para revelaciones |
| psst-sint.wav | PSSHT de respaldo |
